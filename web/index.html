连接步骤

首次连接通常需要 1–2 分钟。

  1. 在设备上打开「开发者选项 → USB 调试」。
  2. 用支持数据传输的 USB 线连接电脑。
  3. 在浏览器弹窗中选择设备，再在设备上允许 USB 调试。
  4. 如果提示接口被占用，先在本机执行 adb kill-server。
Windows 需要设备使用 WinUSB 驱动；未识别时请安装 Google USB Driver 或 UniversalAdbDriver。

浏览器版的边界

需要完整功能？下载桌面客户端

浏览器无法访问局域网 TCP，也无法执行本机 adb / hdc 进程。 无线调试、HarmonyOS hdc、远程控制、签名与 AGC 登录只在桌面客户端中提供。

下载桌面客户端

浏览器版支持

  • USB / WebUSB 直连 Android 设备
  • 设备概览、应用管理、APK 安装
  • 文件浏览、上传、下载、删除
  • Shell 终端、logcat、截图与录屏
  • 按键、文字、分辨率、DPI、旋转

浏览器版不支持

  • 无线调试 / 无线配对 / TCP/IP 切换
  • HarmonyOS hdc 设备
  • 实时远程控制（scrcpy 镜像）
  • HarmonyOS 签名与 AGC 登录
  • 检查更新、公告与驱动安装

安全与隐私

ADB 密钥只保存在当前浏览器的 localStorage 中，首次连接时生成。 清除站点数据后，需要在设备上重新允许 USB 调试。设备数据不会上传到服务器。
